# 性能測定（§5.4、§14.7）

測定環境：クラウドコンテナ（4 vCPU、RAM 15 GB、Linux）。目標の計測環境（ノート PC 8 コア／16 GB、Windows 11・macOS）での
再測定は受け入れ時に行う。`uv run pytest -m perf tests/perf` で再現できる。

| 項目 | 目標 | 結果 |
|---|---|---|
| 単一ランプの解析（再計算） | 5 秒以内 | 平均 16 ms（最大 24 ms） |
| IC/JCT 検索（名称、表記ゆれ吸収） | 1 秒以内 | 平均 4 ms |
| 計算済み区間の表示（詳細＋プロファイル API） | 1 秒以内 | < 0.1 秒（tests/api） |
| 範囲統計比較（各範囲 5,000 ランプ、ブートストラップ込み、9 指標） | 3 秒以内 | 0.06 秒（ADR-0009） |
| 10 万件規模のセグメント検索（DuckDB） | 3 秒以内 | < 0.2 秒 |
| fixture の全パイプライン（ランプ 35、区間 4） | — | 約 2.5 秒 |
| 栃木県の IC/JCT 一覧生成（全パイプライン） | 5 分以内 | 未測定（PBF 未取得） |
| 地図操作 | 30 fps 以上 | 未測定（ソフトウェア描画のコンテナでは計測不可） |
