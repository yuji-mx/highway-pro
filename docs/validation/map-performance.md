# 広域データの地図表示の性能（2026-11-13）

ADR-0015 の検証。州規模の実データ（California）は本環境から取得できないため、同梱 fixture（宇都宮IC〜鹿沼IC）の表示データと
施設を格子状に 600 個複製した負荷データで測った（`scripts/stress_map_server.py 8770 600`。本線 29 万・ランプ 37 万・
一般道 87 万要素、施設 1,800。本線・ランプは California と同程度、密度は約 3 倍）。

測定はヘッドレス Chromium（ソフトウェア描画、1400×900）。パンは 150 ms の移動を 20 回。値は環境で変わるので相対比較用。

## 正しさの確認

- MVT の符号化：別実装（mapbox-vector-tile）で復号し、座標（切り抜き・buffer）・属性の型・空タイル・退化した線を確認
  （`tests/unit/test_vector_tiles.py`）。まとめ版の属性の集約、位置の順の並べ替えの決定性も確認。
- API：ズームごとのタイル、公開 ID によるキャッシュ指定、最小ズーム未満の空タイル、範囲外・未知のレイヤー、まとめ版の GeoJSON、
  要約（`tests/api/test_api.py::test_tiles`）。施設一覧のページ分割・並べ替え・CSV（`test_facilities`）。
- E2E（Playwright）：既存の 18 件（地図上の施設・ランプのクリック、日米の切替を含む）と、一覧の検索・並べ替え・CSV の 1 件が通過。
- 目視：z6・z9（勾配の色分け）・z13 の表示。

## 再現

```bash
uv run python scripts/stress_map_server.py 8770 600
```

http://127.0.0.1:8770/mri を開く（複製と起動に数分かかる）。
