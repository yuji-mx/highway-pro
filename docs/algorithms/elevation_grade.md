# 標高・勾配（§4.7, §4.8）

- 標本化：内部間隔 5 m（ADR-0004）で地理院 PNG 標高タイルを双一次補間（ピクセル中心基準、4 近傍の半分以上が有効なときのみ）。
  欠損は優先順に下位 DEM（DEM5A → DEM5B → DEM10B → Copernicus GLO-30）で補完し、`dem_source` を記録する。
- PNG 復元：x = 2¹⁶R + 2⁸G + B、x < 2²³ → h = 0.01x、x = 2²³ → 無効、x > 2²³ → h = 0.01(x − 2²⁴)。
- 3 系列：`z_dem_raw`（生値）、`z_smoothed`（生値を平滑化）、`z_corrected`（構造物・欠損点を除いて平滑化した後、
  構造物区間を前後各 20 m のアンカー回帰でエルミート補間）。勾配は `z_corrected` から求める。
- 平滑化 5 方式：移動平均・移動中央値・Savitzky–Golay（端部 1 次）・ゼロ位相 Butterworth・外れ値除去（ADR-0005）。既定は外れ値除去 → SG。
- 窓平均勾配 g_w(s) = [z(s+w/2) − z(s−w/2)] / w × 100。窓がはみ出る点は NaN。要素長 < w は端点間平均で `window_truncated=true`。
- 累積上昇・下降：基準値から 0.3 m 以上動いたときだけ計上し、同じ向きが続く間は全量を計上する（ヒステリシス）。
- 連続上り・下り距離：g_100 > +1 %（< −1 %）が続く最長距離。

## 検証（tests/unit/test_elevation.py）

一定勾配 5 %（±0.5 m）で g_100 最大の誤差 ≤ 0.3 ポイント、橋梁下の地表 −7 m 窪みを補正後の勾配が真値 ±0.3、
正弦波で平滑化 5 方式の振幅応答（長波長保存・短波長減衰、外れ値除去は不変）、地理院 PNG の完全一致復元、階段・振動のヒステリシス。
