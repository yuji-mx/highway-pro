# 形状分類（§4.9）

特徴量（`classify/features.py`）：接続本線数、接続方向数、本線接続ランプ数、ループ数（料金所の外側を除く）、一般道接続点数
（料金所があれば料金所位置）、交差道路数、料金所の有無・位置、立体レベル数（ランプと本線接続部の layer の種類）、
終端路線数（施設から 1.5 km 以内に端点を持つ路線チェーン）、本線交差角、旋回 JCT ランプ数（60°〜200°）、次数分布、接続順序。

ルール（`config/classification_rules.yaml`、`rules-1.0.0`）：各分類の必須条件と加点条件。スコア＝満たした加点の重み和 −
3.0 × 満たさない必須条件数。ソフトマックス（温度 0.5）で信頼度にし、必須条件をすべて満たす分類のうち最大を推定分類、
次点を第 2 候補とする。どの分類も必須条件を満たさなければ「分類不能」と理由文を出す。信頼度 < 0.70 は要確認。

検証：合成ネットワークの典型形（トランペット、ダイヤモンド、クローバーリーフ、タービン、Y、ハーフIC、スマートIC、SA）で top1 正解。
実データ fixture では鹿沼IC＝トランペット型、宇都宮IC＝複合型（IC＋日光宇都宮道路 JCT）。
実データでの精度（30 施設以上、top1 ≥ 80 %、top2 ≥ 95 %）は正解ラベル作成後に `docs/validation/` へ記録する。
