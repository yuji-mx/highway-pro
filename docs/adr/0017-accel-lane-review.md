# ADR-0017 加速車線の確認・修正（自動値と手動値を分けて保存）

- 状況：ADR-0016 の自動算出は OSM の描き方に依存し、特に終点（テーパーの終わり）が実際より手前に出ることがある
  （ランプが本線に接続する点を、描いた人がテーパーの途中に置いている場合）。利用者が航空写真で確かめて直せる
  必要がある。利用者の要望：**自動で測った値は上書きせず、手動で直した値と別に保存し、後で比較できること**。
- 決定：
  1. **保存**：手動の確認・修正は既存の manual_edit（追記専用、履歴・取り消しあり）に `field = 'accel_lane'` として
     記録し、最新の有効な修正を `ramp` 表の `accel_manual_*` 列（migration 0003）に反映する。自動の列（`accel_lane_*`、
     `accel_start_*`、`accel_end_*` など）には一切書き込まない。修正の値には、その時点の自動値（`auto_length_m`）と、
     利用者がクリックした位置（`clicked`）も残す。再 build では自動値を計算し直し、手動の値は ID 継承（OSM の way）で
     同じランプに付け直す。
  2. **種類**：`confirmed`（自動値どおりと確認。手動の値＝自動の値）、`corrected`（始点・終点を指定）、
     `not_accel_lane`（加速車線ではない。長さなし）。取り消すと、その前の有効な修正（なければ未確認）に戻る。
  3. **長さの測り方**：道筋＝ランプ全体＋合流ノードから下流の本線（`accel_lane.max_search_m` まで）。指定した点を
     道筋に寄せ、その間の道筋に沿った長さとする。自動の終点より先（本線上）にも終点を置ける。道筋から
     `accel_lane.review_max_snap_m`（30 m）より離れた点は受け付けない。
  4. **API**：`GET /api/ramps/{id}/accel_lane`（自動・手動・差・地図表示用の道筋と区間・履歴）、
     `POST .../accel_lane/measure`（保存せずに長さを確認）、`POST .../accel_lane`（保存）。汎用の `POST /api/edits` では
     `accel_lane` を受け付けない（長さを検証せずに保存されるのを防ぐ）。
  5. **画面**：ランプ詳細に「加速車線の確認・修正」。自動と手動を並べ、差（手動−自動）を表示。地図に道筋・自動・手動・
     指定中の区間と始点・終点を描く。地図をクリックして始点・終点を指定すると長さを先に表示し、メモを付けて保存。
  6. **航空写真**：地図の背景に選べる（既定は表示しない）。日本は地理院のシームレス空中写真（z18 まで）、米国は
     USGS The National Map の航空写真（z16 まで。それより拡大すると引き伸ばし）。タイルは `/api/imagery` 経由で
     `ingest/http.py` から取得し、`data/cache/imagery` に保存する。表示した範囲だけを要求し、オフラインでは保存済みの
     タイルだけを表示する。取得元の URL は画面に渡さない。出典を地図に表示する。
- 検索・統計・難易度は、当面は自動の値（`accel_lane_len_m`）を使う。手動の値を優先するかは、比較の結果を見て決める。
- 結果：`docs/validation/accel-lane.md`（確認・修正の節）。
