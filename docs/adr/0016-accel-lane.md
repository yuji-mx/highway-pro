# ADR-0016 加速車線長の定義と算出

- 状況：本システムの主目的の 1 つは加速車線の長さを測ることだが、従来の算出（合流ノードの直後に本線の `lanes` が
  増え、後で元に戻る区間）は、同梱の実データで日本の流入ランプ 9 本中 0 本、米国 11 本中 3 本しか値が出ず、
  JCT の合流は対象外、除外の理由も残らなかった。OSM の描き方を調べると、多くの合流はランプの way が本線の脇を
  並走し、加速車線の終わりで本線に接続している（`lanes` は変わらない）ため、従来の方法では捉えられなかった。
- 定義（利用者と合意）：
  - 始点：合流車線と本線の隔て部分（ゼブラ・縁石など）が終わり、車線境界が破線になる点。
  - 終点：加速車線が完全になくなる点（テーパーの終わり）。
  - 対象：本線への合流（流入ランプ・JCT 連絡路・SA/PA からの合流）。減速車線は当面対象外。
  - 除外：合流車線がそのまま本線の車線になる「車線追加」、次の出口まで続く「付加車線・織り込み」。
- 決定（`roadmri/network/accel_lane.py`、設定は `analysis.yaml` の `accel_lane`）：
  1. 始点：合流ノードからランプを遡り、本線（同じ路線の上流側）の中心線からの距離が
     「本線の半幅＋ランプの半幅＋許容差」（車線幅は国別、本線・ランプの車線数は `lanes`）以下で続く区間の端。
     ランプが斜めに接続する描き方では、ほぼ合流ノードになる。
  2. 終点：合流ノードで本線の `lanes` が増えている場合は、下流で元の数に戻るノード。増えていない場合は合流ノード
     （ランプが加速車線の終わりで接続する描き方）。
  3. 除外：車線が戻る前に出口へ分岐する、または戻る点が出口の分岐点（付加車線・織り込み）、探索範囲内で戻らない
     （車線追加）、戻る前に別の合流がある、合流点で本線の車線が減っている（矛盾）、合流先の本線がない、
     並走部も車線の増加もなく隔て部分の終わりが特定できない（最小長未満）。除外は長さを null にし、理由を残す。
  4. 保存：長さ、状態、除外理由、方法（並走部／車線数の変化／両方）、信頼度、注記、並走部と増えた車線の長さ、
     始点・終点の座標（`ramp` 表、migration 0002）。
  5. 信頼度：許容差を広げたときに始点が大きく動く（ランプが浅い角度で寄る）ものは「低」、本線の車線数が不明や
     `turn:lanes` に合流の記載がないものは「中」。
  6. 難易度の合流条件（M）と検索・統計の加速車線長は、流入に加えて JCT・SA/PA の合流も対象にする。
- 限界：OSM は手描きなので、始点・終点には数十 m の誤差がありうる。航空写真との照合と手動修正は次の段階
  （地図に始点・終点を表示、航空写真の背景、地図上での修正）で行う。
- 結果：`docs/validation/accel-lane.md`。
