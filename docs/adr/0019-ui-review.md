# ADR-0019 画面操作の見直し（ツールチップ・地域選択・名称・配置・縮尺の案内・表示単位）

利用者の画面確認で見つかった 7 点。日本のみ・米国のみ・日米のテスト用 DB で再現し、原因を確かめてから修正した。

1. **ツールチップ**：道路MRIビューはマウス移動ごとにカーソル座標を親へ渡して再描画しており、地図のホバー処理が
   props 全体に依存していたため、再描画のたびにイベントを付け直して `popup.remove()` していた（表示は 1〜4 ms で
   消えていた。ランプ詳細の地図では残るので、原因はこの再描画と確認）。`mouseout` の解除漏れもあった。
   → イベントは地図ごとに 1 回だけ付け、コールバックは参照で持つ。表示・非表示は `HoverTip`（タイマー）で行う：
   止めて `map.tooltip.show_delay_ms`（500 ms）後に表示、離れて `hide_delay_ms`（200 ms）後に消す、対象の上では保持、
   クリック・地図の移動で消す。カーソルから `offset_px` 離し、画面端では向きを自動で変える。施設の記号の上
   （`facility_hit_px`）では施設を優先し、それ以外はカーソルに最も近いランプ（`hit_px`）。中身は HTML ではなく
   文字列として入れる（OSM の名称を HTML として解釈しない）。配色を地図の暗い背景に合わせた。
2. **地域選択**：初期の地域が「日本」、矩形・円の初期値が栃木の座標で固定されていた。また、選んでいない地域の
   地域プリセット（別の国のもの）の DEM をカスタム範囲に引き継いでいた。
   → 初期の地域は URL（`?area=`）、なければ DB にある国の地域（1 つだけのとき）、日米混在・データなしは日本。
   初期の範囲は DB にあるその地域のデータの範囲。その地域のデータがなければ空欄（州全域などを誤って適用しない）。
   入力は地域ごとに保持する。範囲が選んだ地域（`areas.*.bounds`）の外なら適用できず、どの地域の座標かを案内する。
   カスタム範囲の国・DEM は選んだ地域の既定（`areas.*.country` / `dem`）。
3. **施設名の重なり**：名称を重なりなく配置する（JCT を優先、次に表示範囲の中心に近い順。点の上・下・右・左の順に
   置ける位置を探し、置けなければ出さない。記号は残る）。`map.label_max_chars` より長い名称は末尾の括弧書きを省き、
   正式名称はホバー（title・ツールチップ）と情報パネルで確認する。日本語の名称は長さが短く影響しない。
4. **情報パネルと凡例**：右側の情報パネルと凡例を縦に並べる（重ならない）。表の長い名称は折り返し、数値は折り返さない。
   狭い画面（1023 px 以下）では見出しの配置が `grid-column: 1 / 3` のため暗黙の 2 列目ができ、本文の幅が 0 になって
   道路MRIビューが真っ黒だった → `1 / -1`。640 px 以下ではレイヤー一覧を畳み、情報パネルを開いている間は凡例を隠す。
5. **一般道と縮尺の案内**：一般道を明るく・やや太くした（本線・ランプとは区別）。レイヤーごとに、表示されない理由を
   「ズームN以上」（縮尺の条件）か「この範囲になし」（データなし）で示す。名称は「IC・SA/PA 名はズーム 11 以上」
   「JCT 名はズーム 9 以上」を分けて示す。
6. **表示名・異常表示**：OSM の名称の「;」区切り（複数の名前）を画面では「／」でつなぐ（DB・API・CSV の値は元のまま）。
   経路異常のコードには SPEC §4.5.5 の条件に沿った短い名称（`anomalies.ANOMALY_LABELS`）と既存の説明を表示し、
   元のコードは title と詳細に併記する。
7. **表示単位**：仕様（§5.9、ADR-0013）は内部・API を SI とし、画面で切り替えるとだけ定めており、メートル法を初期値に
   する理由はない。地域設定には米国の州に `units: imperial` があるが画面で使っていなかった。
   → 利用者が選んだことがない場合だけ、公開中の地域がすべて `units: imperial` なら ft・mph を初期値にする（`/api/meta`
   の `default_units`）。日米混在は m・km/h（日本のデータが基準の比較が多いため。切り替えは保持される）。
   利用者が選んだ単位（ブラウザに保存）は上書きしない。

設定（`config/settings.yaml`）：`map.tooltip`、`map.label_max_chars` / `label_gap_px` / `label_mark_px`、`areas`。
いずれも画面表示の設定で、解析の config_hash には含めない。
