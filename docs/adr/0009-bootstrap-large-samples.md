# ADR-0009 大標本での中央値ブートストラップ

- 状況：範囲統計比較の性能目標（各範囲 5,000 ランプで 3 秒以内）に対し、2,000 回の復元抽出で中央値を求めると
  9 指標で約 5 秒かかった。
- 決定：n ≤ 2,000 は通常の復元抽出。n > 2,000 は「復元抽出標本の中央値 ≤ x_(j) となる確率 = P(Binom(n, j/n) ≥ m)」
  を使い、一様乱数の逆変換で中央値を直接サンプリングする（偶数 n は上下 2 つの順序統計量を同じ乱数で求め平均）。
  乱数シードは固定で、同じ入力では同じ結果になる。
- 検証：n = 2,001 と 2,400 で通常の復元抽出との CI 端点の差は CI 幅の 15 % 未満（テストで確認）。5,000×5,000 で 0.06 秒。
