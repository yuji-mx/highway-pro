# ADR-0018 加速車線一覧（自動と手動の比較）

- 状況：自動の加速車線長（ADR-0016）の精度と偏りを、航空写真で確認・修正した値（ADR-0017）と比べて把握したい。
  利用者の方針：**検索・統計・難易度は当面は自動の値のまま**。十分な件数を確認して精度と偏りが分かった時点で、
  有効な値を「確認済みなら手動、そうでなければ自動」にするかを決める。
- 決定：
  1. 画面「加速車線一覧」（`/accel`、サイドバー 10）：本線への合流ごとに、自動の判定（測定・除外と理由）、判定方法、
     信頼度、自動の長さ、手動の長さ、差（手動−自動）、確認状態（未確認・自動値どおり・修正・加速車線ではない）、
     確認者・日時・メモを並べる。サーバー側で絞り込み・並べ替え・ページ分割し、行からランプ詳細（確認・修正）へ移る。
  2. 要約：自動と手動の両方に長さがあるもの（自動値どおり・修正）で、差の偏り（平均）・中央値・平均絶対誤差・RMSE・
     絶対値の 90% 点・手動のほうが長い割合を、全体・信頼度別・判定方法別に出す。判定の食い違い（自動では測ったが
     「加速車線ではない」、自動では除外したが手動で測った）を数える。自動 × 手動の散布図（一致線つき、信頼度で色分け）。
     要約は一覧と同じ絞り込みに従う（例：国別・種類別の偏り）。
  3. CSV（`GET /api/accel_lanes.csv`）：一覧と同じ条件の全件。自動・手動の値と始点・終点の座標、除外理由、注記を含む。
     長さは表示単位に関係なく m。Excel で開けるよう UTF-8 BOM 付き。
  4. API：`GET /api/accel_lanes`（一覧）、`GET /api/accel_lanes/summary`（要約）、`GET /api/accel_lanes.csv`。
- 有効な値の切り替え（手動を優先）は、この画面で精度と偏りを確認したうえで別途決める。
