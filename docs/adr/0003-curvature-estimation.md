# ADR-0003 曲率推定（頂点スプラインと適応帯域）

- 状況：§4.6 の手順（線形補間 → 等間隔 → Savitzky–Golay → 三点外接円）を、OSM 風の不等間隔点列（間隔 5〜25 m、
  座標ノイズ ±0.3 m）に適用すると、頂点の折れ点に曲率が集中し最小 R を 30〜75 % 過小評価した。§14.1 の基準
  （誤差 ≤ 5 %、R=1000 は ≤ 10 %）を満たせない。
- 決定：再サンプリングの補間を「頂点列の罰則付き平滑化スプライン（lam = h⁴/平均頂点間隔）」に置き換える。
  帯域 h は 0.2 × 推定最小 R（4〜80 m）に反復で合わせ、平滑化による円の縮み（R' ≈ R − h²/R）を
  κ_corr = κ / (1 + h²κ²) で補正する。その後は §4.6 どおり Savitzky–Golay、三点外接円、移動中央値、最大値をとる。
  曲率変化率は窓 40 m（本線 120 m）の線形回帰傾きとし、スプラインの自然境界条件の影響を受ける端部 2h を除外する。
- 結果：合成円弧（R=50/100/300/1000、ノイズ ±0.3 m）で最大誤差 3.4 %、クロソイドの曲率変化率誤差 2〜3 %。
  パラメータは `config/analysis.yaml` の `geometry_smoothing.vertex_spline`。
