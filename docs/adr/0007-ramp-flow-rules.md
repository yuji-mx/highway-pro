# ADR-0007 論理ランプと flow 判定、形状特徴量

- 縮約：リンクのノードのうち「無向次数 2、入次数＝出次数、本線・一般道・料金所に接しない」ものを内部点とし、
  それ以外の点の間を 1 本の論理ランプとする。双方向（oneway=no）のリンクは 1 本だけ残し flow=two_way とする。
- flow：ランプから上流・下流へリンク上をたどって到達する端点の種類で決める。上流に本線・下流に一般道（料金所）
  → exit、逆 → entry、両側が異なる本線 → jct_link、同じ本線 → collector_distributor、料金所と一般道の間 → toll_link、
  休憩施設ポリゴン内の行き止まり → facility_link。
- 特徴量：料金所の外側（toll_link・two_way）のループは IC 本体の形状に含めない。料金所がある場合は全交通が
  料金所を通るため、料金所位置を一般道接続点とみなす（鹿沼IC のように料金所の先でループして一般道に接続する
  トランペット型を正しく判定するため）。
- 施設：本線に出口ノードもランプも持たない `highway=services`（道の駅など）は施設から除外する。
