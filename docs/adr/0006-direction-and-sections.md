# ADR-0006 上下線の判定と区間距離

- 上下線：本線エッジの始点・終点と路線起点（`config/routes.yaml` の origin）の距離を比べ、起点に近づく向きを「上り」とする。
  判定が曖昧なエッジ（距離差が長さの 20 % 未満）は前後の同一路線エッジから継承する。routes.yaml にない路線は
  最西端（同値は最南）の端点を起点とみなす（暫定）。
- チェーン：路線×方向ごとの弱連結成分で最長路を線形参照（弧長 s）の基準とし、成分外のノードは射影で s を与える。
- 区間距離：§17-1 の暫定決定どおり `standard` ＝ 最初の分流点と最後の合流点の中点どうし。施設が分流だけ・合流だけの
  場合は接続点の最小・最大の中点、接続点がない場合は施設代表点の射影位置を使う。`mainline_connection` は
  「起点施設の最初の本線接続点 → 終点施設の最初の本線接続点」と定義した。`toll_to_toll` は料金所→合流点、
  分流点→料金所のリンク上の最短距離を加えて求める。
